# 夏目数码 · 角色业务测试用例

把自己当成真实使用者，一个角色一个角色地把业务走一遍，同时看界面是否清楚、颜色有没有问题。

本目录与 `docs/test-cases/` 无关，不要混用，也不要以那边的用例或结果作为依据。

## 执行者要做的事

1. 按“执行顺序”走完所有用例，每条记录通过、失败或阻塞。
2. 每个标了 📷 的步骤都要看界面并截图，按 [12-界面检查标准.md](12-界面检查标准.md) 判断。
3. 发现问题按“问题记录”的格式写进报告，**不要修改业务代码**。
4. 全部结束后输出报告，放在 `docs/role-tests/results/<日期>/`。

## 准备环境

1. 用微信开发者工具打开仓库根目录，确认开发版走 mock（`miniprogram/config/index.js` 的 `useMock: true`）。全程不需要启动后端。
2. 进入底部「我的」→「开发调试」→ 点 **加载测试设备**，提示“已加载，共 74 台设备”。
3. 用「开发调试」→「切换模拟身份」切换角色。员工身份切完后点「员工经营台」进入。
4. 主题在「我的」→「外观」切换：浅色、深色、零售绿。

### 必须遵守

- **重新编译会清空全部 mock 数据**，包括测试设备和你做过的业务。只在需要重置时才编译；编译后重新点“加载测试设备”，并把已消耗的设备状态当作已重置。
- 改动过的数据在切换身份后仍然保留，这正是跨角色流程能接力的原因。
- 打开过分享链接后，后续请求都会带这个分享身份。做完分享类用例，回首页点「浏览全部现货」清掉，否则后面的顾客用例结果会错。
- 用例指定的设备不要挪用。每条流程独占设备，用错会连累后面的用例。
- 代理下单锁定 30 分钟，超时自动释放。相关流程要连续做完。
- 用例里「」内是界面原文，可以直接比对。

### 模拟器里无法完成的操作

| 操作 | 处理办法 |
|---|---|
| 扫码按钮 | 改用输入框手动输入编号或串码；同时记录扫码按钮本身能否点击。真机扫码不在本轮范围 |
| 选图、拍照上传（凭证、实拍） | 拦截 `wx.chooseMedia`，返回 `/assets/images/phone_blue_main.jpg` 作为临时文件 |
| 保存到相册、转发给好友、打开设置 | 只验证按钮可点、不报错，实际结果记为“未验证” |
| 打印标签、收银小票 | 功能未做，页面提示“打印机对接待实现”是预期，不算缺陷 |
| 正式小程序码 | 未配置，海报页提示「暂无法生成可扫码海报，请使用小程序卡片分享」是预期 |
| 真实短信、微信登录 | mock 模式不校验，本轮不覆盖 |

## 执行顺序

1. **基线**：加载数据后先做 01～04 中标“基线”的用例，这些用例的数字只在没有任何写操作时成立。
2. **单角色**：01 → 10 依次执行。
3. **跨角色**：11 全部执行，顺序不能打乱，部分流程依赖前面的结果。
4. **界面巡检**：数据最丰富时做 12 的全站三主题巡检。

用例标记：**基线**表示依赖刚加载的数据；📷 表示这一步要截图检查。

## 问题记录

```markdown
### BUG-001 一句话描述
- 级别：P0 / P1 / P2 / P3
- 用例：SAL-03
- 身份与主题：销售 / 深色
- 页面：packages/staff/pos/index
- 步骤：1. … 2. …
- 期望：…
- 实际：…
- 截图：results/2026-11-07/SAL-03-dark.png
- 控制台：有无报错，贴原文
```

| 级别 | 含义 |
|---|---|
| P0 | 金额算错、库存错乱、越权看到不该看的数据、流程卡死无法继续 |
| P1 | 主流程走不通或结果与用例不符；文字完全看不清；按钮被遮挡点不到 |
| P2 | 次要功能异常；对比度明显不足但仍可辨认；布局错位、文字截断 |
| P3 | 文案、间距、细节体验 |

## 报告格式

`report.md` 包含：执行时间；通过 / 失败 / 阻塞 / 未验证 的数量；按级别排序的问题清单；各角色结论；三套主题各自最严重的问题；未覆盖内容。

截图命名：`<用例编号>-<主题>.png`，如 `CUS-05-dark.png`。全站巡检用 `UI-<页面序号>-<主题>.png`。

## 判断通过的总原则

无论用例有没有写，出现下面任何一条都算失败：

- 控制台有 JS 报错，或出现 `[mock] 未实现`。
- 顾客、同行、代理页面出现成本、供应商、内部备注、完整 IMEI；顾客页面出现同行价。
- 界面显示 `undefined`、`null`、`NaN`、空白金额或原始字段名。
- 按钮点了没反应，也没有任何提示。
- 操作失败却提示成功。

## 本轮不能证明什么

mock 是单线程内存模拟，通过只说明**页面和业务规则**符合预期。真实数据库事务、并发抢购、MySQL 权限、线上接口，本轮都没有覆盖，报告中不要写成已验证。
