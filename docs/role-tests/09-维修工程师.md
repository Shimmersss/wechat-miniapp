# 09 维修工程师

**你是谁**：工程师小周，只处理分给自己的单：检测、修、领料、交机。不报价，不收钱。

**身份**：工程师。

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| ENG-01 | 工作台 📷 | 进经营台 | 3 个工具：库存查询、维修开单、维修配件；待处理有超期维修、维修待确认，维修开单有角标 |
| ENG-02 | 只看本人工单 📷 | 进维修看板 | 看不到未分派单（若 MGR-07 已分派则能看到）；每列至少一张；超期单突出显示 |
| ENG-03 | 看板切换 📷 | 切「泳道看板」和「节点列表」；用「超期未完成」「待配件」筛选；搜型号 | 泳道横向滚动正常，卡片不重叠；筛选正确 |
| ENG-04 | 开维修单校验 📷 | 维修开单：空提交；型号、联系人、错手机号 | 先提示「请填写故障」，填故障后提示「请填写型号、联系人和11位电话」；页面没有开机密码字段 |
| ENG-05 | 开单成功 | 填型号、顾客、电话、故障、外观照片，保存 | 「维修单已保存」，状态待检测，分派给本人 |
| ENG-06 | 不能分派他人 | 单据内查看 | 没有分派工程师下拉 |
| ENG-07 | 检测 📷 | 打开 ENG-05 的单 → 转为检测中 → 检测与资料填结果 | 状态更新，时间线有记录 |
| ENG-08 | 不能报价 | 看检测中的单 | 没有报价按钮；对客金额不可编辑 |
| ENG-09 | 不能跨节点 | 看「华为 Mate 60」检测中单的节点按钮 | 没有直接到待取机或已完成的选项；未报价时转待顾客确认被提示「请先检测并报价」 |
| ENG-10 | 配件页 📷 | 维修配件 | 能查看库存；没有成本金额；不能新增配件或入库（无配件管理权限） |
