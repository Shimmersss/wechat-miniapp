# 10 财务

**你是谁**：财务阿梅，看账、退款、给代理转账、登记维修收支。能看毛利，不能动库存，不能开单。

**身份**：财务。

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| FIN-01 | 工作台 📷 | 进经营台 | 4 个工具：库存查询、维修开单、维修配件、代理收益 |
| FIN-02 | 字段可见性 | 打开 t03 | 成本可见；批发、代理底价、供应商、内部备注不可见；串码打码；没有改价、分享开关不可操作 |
| FIN-03 | 报表 📷 | 报表切今日、本周、本月 | 有毛利、动销率，有导出按钮，数字与销售单对得上 |
| FIN-04 | 退款校验 📷 | 打开王小明 t51 的单 → 登记退款 / 退货：不选设备；仅退差价填 `8000`；填 `abc` | 依次「请选择退款设备」、提示「超过剩余可退金额」、「请填写有效退款金额，最多两位小数」，都不生效 |
| FIN-05 | 需要原因 | 选仅退差价 100，提交，弹窗留空确认；取消 | 提示「请填写操作原因」，未退款；取消后回到编辑 |
| FIN-06 | 收益转账 📷 | 代理收益 → 待转账：勾 ¥300 那笔 → 标记已转账，留空；再填说明 | 底部显示已选笔数和合计；留空被拦截；成功后提示已标记，待转账减少 |
| FIN-07 | 查收益状态 | 切已转账、已冲回、全部 | 已转账有说明和时间；冲回记录金额可辨认 |
| FIN-08 | 维修收款 📷 | 打开 iPhone 13 单（维修中）→ 登记收款 ¥199，填方式和说明；再登记 ¥1 | 第一笔成功，对客已收 ¥199；第二笔提示「超过报价或可退金额」 |
| FIN-09 | 不能处理节点 | 看维修单 | 没有节点推进、领料按钮（无维修处理权限） |
| FIN-10 | 导出 | 导出销售退款明细 | 要求原因；日志有记录 |
| FIN-11 | 能力边界 | 底部「开单」；库存页 | 开单弹「无权限」，能返回；没有入库、出库、盘点、改价 |
