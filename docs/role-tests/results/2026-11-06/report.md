## P2 问题

### BUG-001 深色主题下库存总览主块比页面背景更暗（凹进去而非浮起来）

- 级别：P2
- 用例：UI-29
- 身份与主题：老板 / 深色
- 页面：`packages/staff/inventory/list`
- 实测：主块 RGB `(11,12,14)`，页面背景 `(22,15,33)`，主块**比背景暗 11 个色阶**
- 期望：主块应比页面背景亮（浅色主题主块 238 对 205、零售绿 246 对 203，都是浮起的）
- 影响：卡片边界消失，「在库 53 台」这块看起来是凹槽而不是汇总卡，与另外两个主题的层次关系相反
- 截图：`29-dark.png` / `29-light.png` / `29-retail.png`
- 根因（供修复参考）：`.summary` 用 `var(--c-glass)`；深色主题的 `--c-glass` 是 `rgba(62,68,80,.78) → rgba(34,37,44,.72)` 半透明渐变，叠在 `#0B0C0F` 页面上得到接近纯黑的结果

### BUG-002 深色主题下主按钮 / 选中态用蓝紫，与另两个主题的「墨黑 / 深绿」语义不一致

- 级别：P2
- 涉及页面：首页品牌标签、借还列表分段、型号模板「新增型号」按钮、我的页主题选择器、成为代理页 CTA 等
- 现象：同一控件三主题的选中色不同 —— 浅色近黑 `#111215`、深色**蓝紫 `#6E7BFF`**、零售绿深绿 `#1C2B20`
- 影响：功能上可辨（B4 合格），但在「我的 → 外观」里选「深色」时，选中态显示为蓝色块，容易被理解成「蓝色主题」而不是「深色主题」
- 截图：`04-dark.png`（主题选择器）、`42-dark.png`（分段控件）、`27-dark.png`（主按钮）
- 根因（供修复参考）：深色主题把 `--c-action` 定义为品牌蓝紫，避免 `--c-ink` 反转后变大白块；但 `--c-action` 同时被选中态控件复用

### BUG-003 深色主题维修看板汇总卡与页面背景几乎融为一体

- 级别：P2
- 页面：`packages/staff/repair/board`
- 实测：顶部汇总卡区域平均亮度比下方内容区**低 12**
- 影响：四个指标（今日开单 8 / 队列完成率 12.5% / 平均完工时长 0h / 维修毛利 ¥450）虽可读，但卡片没有边界，看起来像散落在页面上
- 截图：`38-dark.png`
- 与 BUG-001 同源（`--c-glass` 在深色下过暗）

## P3 问题

### BUG-004 零售绿主题下输入框与卡片同为白色，边界不明显

- 级别：P3
- 页面：`packages/staff/pos/index`、`packages/shop/consult/index`
- 现象：零售绿的 `--c-well` 定义成 `#FFFFFF`（方案 A「白卡托图标」的做法），但输入框也用 `--c-well`，落在白卡上就没了边界
- 截图：`35-retail.png`

### BUG-005 深色主题筛选项背景与卡片接近

- 级别：P3
- 页面：`packages/staff/audit/index`
- 现象：「全部动作 / 全部人员 / 开始日期 / 结束日期」四个筛选块背景与卡片差约 8 个色阶，靠文字才能分辨边界
- 截图：`52-dark.png`

### BUG-006 商品摄影图的浅灰底在深色 / 零售绿下像一块亮补丁

- 级别：P3
- 页面：`packages/shop/product/index`、`pages/shop/index` 列表
- 现象：产品图本身是浅灰背景，深色主题里与近黑底色反差很大
- 判断：**不是 UI 缺陷**，是图片素材问题。需要深色版素材或加渐隐遮罩
- 截图：`07-dark.png`、`01-dark.png`

### BUG-007 操作日志 / 员工页的技术性 id 直接暴露给用户

- 级别：P3
- 页面：`packages/staff/audit/index`
- 现象：列表里显示 `po_1793969841620_4`、`sale_1793969841618_43` 这类内部单据 id
- 判断：属于设计取舍（审计场景可能确实要看到原始 id），记录但不建议改
- 截图：`52-light.png`
