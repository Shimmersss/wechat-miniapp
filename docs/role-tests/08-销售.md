# 08 销售

**你是谁**：店员小李，站柜台开单、跟进顾客、发分享。不看成本和毛利，不能退款，不能改成交价。

**身份**：销售。

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| SAL-01 | 工作台 📷 | 进经营台 | 5 个工具全在常用区，没有「更多」：扫码收银、库存查询、顾客跟进、分渠道分享、代理订单 |
| SAL-02 | 字段可见性 | 库存列表和 t03 详情 | 成本、代理底价、供应商、内部备注「无权限查看」；批发价可见；串码 `35****0034`；用完整串码以外的数字搜索提示「串码查询请扫描完整 IMEI」 |
| SAL-03 | 收银加减设备 📷 | 开单页输入 `t11` 添加，再输入 `t11`，再移除 | 添加后合计 ¥5,799；重复提示「已在收银单中」；移除后回到「待核算」，确认按钮不可点 |
| SAL-04 | 零售开单 📷 | 用串码 `359999000000125`（t12）添加，填顾客、电话、选支付宝，点「确认已收款并出库」 | 确认后「销售单已保存」，金额 ¥3,899；t12 变已售；顾客端消失 |
| SAL-05 | 批发开单 | t13 打开「按批发价成交」 | 合计从 ¥6,899 变 ¥6,500；出库成功，销售单渠道为批发 |
| SAL-06 | 多台开单 📷 | 点「从库存选择设备（可多选）」，选 t14、t17 →「去收银（2 台）」 | 合计 ¥6,398；一单成交，两台都已售 |
| SAL-07 | 库存页出库 | 库存 → 手动出库，勾选 t16 → 去收银；已售设备不能勾选 | 进入收银且带入 t16；不要提交，移除即可 |
| SAL-08 | 不能改价 | 收银单看设备 | 没有「自定义成交价」输入框 |
| SAL-09 | 不可售设备 | 依次输入 `t51`、`t70`、`t99`、借入设备串码 `359999000009019` | 都提示「未找到可售设备」，不进收银单 |
| SAL-10 | 收款凭证 | 开单时添加截图 → 移除 → 再加；成交后详情查看；详情「补传」填说明 | 最多 9 张；详情能查看；补传写日志 |
| SAL-11 | 销售记录 📷 | 销售记录：按单号、顾客搜索；选日期区间；只选开始日期；切状态；切销售员；清除 | 只选一个日期提示「请选择完整起止日期」；开始晚于结束提示「开始日期不能晚于结束日期」；销售员筛选结果正确 |
| SAL-12 | 销售详情 | 打开 t51 的单 | 有成交快照、设备、凭证、退款记录；**没有**「登记退款 / 退货」按钮；没有毛利、成本 |
| SAL-13 | 顾客跟进 📷 | 顾客跟进：切类型和状态，搜手机号，打开刘先生的咨询 → 选已联系 → 填内部说明 | 状态变已联系；员工能看到内部说明；切顾客打开同一记录，状态已更新，但**看不到内部说明** |
| SAL-14 | 分享商品 📷 | 分渠道分享：搜 `Mate`，加入 t08，切同行分享生成；预览；复制文案；切代理分享 | 同行分享显示批发价；代理分享页提示由代理本人生成，生成时报「仅已审核通过的代理可生成代理分享」 |
| SAL-15 | 能力边界 | 底部「报表」；直接打开员工管理、操作日志、型号模板 | 报表无毛利；其余页弹「无权限」，关闭后能返回 |
