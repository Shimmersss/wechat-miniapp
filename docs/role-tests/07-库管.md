# 07 库管

**你是谁**：库管小赵，管货：验收、入库、复检、贴标、盘点、借还。不改价，不看成本和批发价。

**身份**：库管。

## 入库

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| WH-01 | 工作台 📷 | 进经营台 | 4 个工具全在常用区，没有「更多」：入库登记、快递验收、库存查询、出借借入 |
| WH-02 | 字段与能力 | 打开 t03；看库存页 | 成本、批发、代理底价、供应商「无权限查看」；有完整串码和内部备注；没有改价按钮 |
| WH-03 | 单台入库校验 📷 | 入库登记：不选型号提交；选型号不填参数提交；不勾确认提交；串码填错误样本 | 依次「请先选择型号」、提示缺的参数、「请先确认已完成逐台实机验收」、串码校验失败 |
| WH-04 | 单台入库成功 📷 | 型号 iPhone 17 Pro，参数填齐（含供应商，这里是手填文本），IMEI1 用 N8，上传收货凭证和实拍，成本 6000、零售 6999、批发 6500、代理底价 6600，打开三个分享开关，勾确认，提交 | 弹「入库成功」；库存多一台，状态在库可售；打开详情，自己看不到成本；切顾客能看到它 |
| WH-05 | 串码查重 | 再次入库用 N8；用 `359999000000034`（t03） | 提示已存在，未生成库存 |
| WH-06 | 定价辅助 | 点成本快捷档位；填目标利润或毛利率 | 成本填入，建议价填入；可手动改；实际保存以提交的值为准 |
| WH-07 | 整备中入库 | 用 N9 入库，整备状态选「正在整备」 | 入库后状态为复检待入库，分享开关全关，顾客看不到 |
| WH-08 | 批量入库 📷 | 切批量入库，选 iPhone 16 Pro，填公共参数；增加到 2 台，填 N10、N11；展开第 2 台改电池；提交 | 按钮「批量入库（2台）」；两台入库，第 2 台差异值生效 |
| WH-09 | 批内重复 | 批量里两行填同一串码 N12 | 提示串码无效或批内重复，一台都不入库 |

## 盘点

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| WH-12 | 新建校验 | 库存 → 库存盘点，取消所有状态后开始 | 提示「请至少选择一种库存状态」 |
| WH-13 | 按分类盘点 📷 | 选「穿戴设备」，默认状态，说明填「穿戴抽盘」，开始 | 应盘 3 台（在做其他流程前），进入盘点页，进度 0 / 3 |
| WH-14 | 盘到与异常 📷 | 依次输入 `t17`、t45 的串码 `359999000000455`、`t51`、`bad-code`、再 `t17` | 依次「已盘到」「已盘到」「已售，不在本次盘点范围」「系统里没有这台设备」「这台已经盘过」；反馈颜色有区别；进度 2 / 3，异常 2 |
| WH-15 | 中途退出再进 | 返回上级，再从「进行中的盘点」进入 | 记录都在，进度不丢 |
| WH-16 | 结束与差异处理 📷 | 结束盘点；缺失的 t26 处理为「确认丢失」填说明；两条异常处理为「已处理」 | 结果：应盘 3、盘到 2、缺失 1、异常 2；有「还有 3 项差异未处理」；处理后减少；**t26 状态不变**（盘点不改库存） |
| WH-17 | 作废盘点 | 新建一单，扫一台，作废，填原因 | 状态已作废，不生成结果；设备不受影响 |
