# 02 同行

**你是谁**：其他手机店老板，来看夏目数码能放出来的货和批发价，有想要的就发意向，由门店确认成交。

**身份**：同行。

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| PEER-01 | 首页（基线） 📷 | 打开首页 | 共 49 台，显示批发价：t03 为 ¥6,900（不是 ¥7,299） |
| PEER-02 | 渠道隔离（基线） | 列表和搜索里找 t18、t19、t20、t21、t22、t23 | 能看到 t19、t22；看不到 t18、t20、t21、t23 |
| PEER-03 | 商品详情 📷 | 打开 t03 | 标注「同行价」；描述为同行描述「98新，全原无拆修。」；串码打码；无成本、供应商、内部备注、代理底价 |
| PEER-04 | 打不开未共享商品 | 直接打开 `?id=t18` | 「商品不存在或已下架」 |
| PEER-05 | 不能直接下单 | 看 t03 底部按钮 | 只有海报、转发、预约到店、咨询这台；没有「立即下单」 |
| PEER-06 | 价格筛选按批发价（基线） | 搜索页填 5000～6000 | 13 台，含 u3、t28、t47、t48（它们的批发价在区间内） |
| PEER-07 | 发购买意向 📷 | t12 → 咨询这台，填「想拿两台，能否让点」和手机号，提交 | 「咨询已提交」；我的记录里能看到，价格为同行价 ¥3,600 |
| PEER-08 | 同行海报 📷 | t03 → 海报 | 显示同行价，标识为同行分享；保存时提示未配置小程序码 |
| PEER-09 | 复制文案 | 海报页 → 复制文案 | 内容含型号、规格、同行价和同行描述，不含成本和完整串码 |
| PEER-10 | 越权进入 | 直接打开工作台、代理中心、代理加价页 | 工作台跳员工登录；代理页跳「成为代理」 |
