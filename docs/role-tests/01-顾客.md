# 01 顾客

**你是谁**：第一次打开小程序的普通买家，想买一台二手手机，想知道价格、成色，可能咨询或到店。

**身份**：顾客。主题默认浅色。

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| CUS-01 | 首页浏览（基线） 📷 | 打开首页，滚到底 | 共 50 台，分页加载正常；顶部是搜索框，没有夏目数码品牌条；品牌入口 8 个（苹果、华为、小米、荣耀、OPPO、vivo、三星、一加手机），图片位不破图；搜索框和排序筛选栏滚动时吸顶；底部「— 每台设备独立检测 · 公开机况 —」 |
| CUS-02 | 品牌筛选（基线） | 依次点华为、小米、荣耀手机，再点一次荣耀取消；点一加手机 | 分别 7、6、4 台，取消后 50 台；选中项有明显区别；一加无现货时显示「暂无符合条件的现货，换个条件试试」 |
| CUS-03 | 渠道隔离（基线） | 在全部列表和搜索中找 t19、t20、t21 的设备 | 都找不到；t18、t22 能看到 |
| CUS-04 | 分类浏览 📷 | 进「分类」，切换手机、平板、笔记本、穿戴设备 | 手机下有苹果、华为、小米、荣耀；平板有苹果 iPad Pro、华为 MatePad；笔记本、穿戴各有苹果 |
| CUS-05 | 型号精确筛选（基线） | 手机 → 新机 → 点 Mate 70 Pro；返回选二手机再点一次 | 新机 1 台（t09），二手 5 台；搜索页顶部有「型号：Mate 70 Pro · 取消」，点取消后回到全部结果 |
| CUS-06 | 未建档型号 | 分类里点 iPhone 17 | 用关键词搜索；无结果时显示「没有符合条件的现货，换个条件试试」 |
| CUS-07 | 关键词搜索（基线） 📷 | 搜 `Mate`、`512G`、`黑色`；再搜 `不存在的型号` | 分别 7、15、17 台；最后空结果；首屏有历史搜索，点历史可重搜，「清空」后消失 |
| CUS-08 | 成色与新旧筛选（基线） 📷 | 展开筛选，选新机；重置；选准新 | 新机 5 台，准新 7 台；筛选按钮显示「筛选（1）」 |
| CUS-09 | 电池筛选边界（基线） | 依次选 90%、85%、80% 以上 | 43、46、49 台；80% 含 t06（80），不含 t07（79） |
| CUS-10 | 价格筛选（基线） | 填 5000～6000 点确定；再填最低 6000、最高 5000 | 第一次 10 台；第二次提示「最低价不能高于最高价」，列表不被清空成错误数据 |
| CUS-25 | 首页排序（基线） 📷 | 依次点「价格」两次，再点「综合排序」 | 先从低到高，再从高到低，箭头高亮对应方向，最后恢复默认顺序；同行身份按批发价排序 |
| CUS-26 | 首页下拉筛选 📷 | 点成色、价格区间、电池健康：选项后看确定按钮台数；点重置；点遮罩；填最低 6000、最高 5000 点确定 | 筛选栏滚到吸顶位置，底部导航收起；确定按钮显示实时台数；点遮罩不生效并收起；价格错误提示「最低价不能高于最高价」 |
| CUS-27 | 型号选择 📷 | 点「型号」，切分类、品牌，选 iPhone 17 Pro 确定；再点品牌入口 | 底部弹层盖住搜索框和底栏；列表只剩 7 台该型号，栏上显示型号名；选品牌后型号条件被清除 |
| CUS-28 | 筛选抽屉 📷 | 点「筛选」，选型号、新旧、成色、价格、电池，确定；再进抽屉重置并确定 | 右侧抽屉滚动正常，从抽屉选型号后回到抽屉不直接生效；确定后「筛选」显示条件数量；重置后恢复 |
| CUS-11 | 组合与重置 | 同时选成色、电池、价格，点「重置筛选」 | 计数归零，结果恢复全部 |
| CUS-12 | 商品详情 📷 | 打开 t03 | ¥7,299，标注「零售价」；串码 `35****0034`，提示「完整串码到店核验」；有放心承诺、单机检测与参数、相似在售；没有成本、批发价、供应商、内部备注；参数里没有整备、门店等内部字段 |
| CUS-13 | 边界商品 📷 | 打开 t27、t28、t29、t25、t24 | 长名称、长描述不撑破布局；t28 无图时没有破图；t29 描述为空时不显示 undefined；¥99,999.99、¥1,699.99 显示完整 |
| CUS-14 | 打不开未开放的商品 | 直接打开 `/packages/shop/product/index?id=t19` 和 `?id=t21` | 显示「商品不存在或已下架」，有「重试」和「浏览店铺现货」；后者能回首页 |
| CUS-15 | 咨询校验 | t02 详情 → 咨询这台，不填内容提交；填内容不填手机号提交；手机号填 `123` | 依次提示「请填写咨询内容」或「请填写11位联系手机号」，未产生记录 |
| CUS-16 | 提交咨询 📷 | 填内容和手机号 `13900001111`，提交 | 显示「咨询已提交」；能进详情看到跟进进度，状态「待跟进」；再次点提交不会重复生成 |
| CUS-17 | 预约到店 📷 | t02 详情 → 预约到店，不填称呼提交；填全后提交 | 先提示「请填写称呼、日期和时段」；日期只能选今天起 30 天内；成功后「预约意向已提交」；页面提示门店确认、不锁库存或价格 |
| CUS-18 | 不指定设备咨询 | 我的 → 咨询与预约到店，只填内容和手机号 | 提交成功，记录里没有设备信息，也不显示 undefined |
| CUS-19 | 我的记录 📷 | 我的 → 我的咨询与预约记录，切换全部、咨询、预约、代理下单；用状态下拉筛选 | 只看到“顾客”身份的记录，看不到同行或别人的；空结果显示「暂无对应记录」 |
| CUS-20 | 取消预约 | 打开 CUS-17 的记录 → 取消本次意向，留空确认；再填原因确认 | 留空提示「请填写操作原因」且未取消；填写后状态「已取消」，时间线有记录，取消按钮消失 |
| CUS-21 | 分享海报 📷 | t03 详情 → 海报 | 显示零售价；有复制文案、发给好友、保存按钮；保存时提示「暂无法生成可扫码海报，请使用小程序卡片分享」，不出现假二维码 |
| CUS-22 | 了解代理 📷 | 底部「成为代理」，滚到底 | 算账示例、四个卖点、四步流程和规则完整，口号「让价格透明 · 让产品放心」未改；按钮不被底部导航挡住；按钮文字「申请成为代理」 |
| CUS-23 | 代理申请校验 | 点申请，依次空提交；手机号填错；不勾协议；邀请码填 `WRONG123` 提交 | 依次提示「请填写姓名或昵称」「请填写 11 位手机号」「请选择所在地区」「请先阅读并同意代理协议」；错误邀请码显示「邀请码无效」，不创建申请。正式申请在 FLOW-20 做 |
| CUS-24 | 越权进入 | 直接打开工作台、代理中心、库存页 | 员工页跳到员工登录页；代理中心跳到「成为代理」；都看不到业务数据 |
