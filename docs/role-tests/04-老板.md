# 04 老板

**你是谁**：店主，什么都能看什么都能改。每天看经营数据，调价，管模板、员工和代理。

**身份**：老板。基线用例要在任何写操作之前做。

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| BOSS-01 | 工作台（基线） 📷 | 进员工经营台 | 15 个快捷入口；待处理：咨询预约 4、代理申请 2、代理收益 1、借还逾期 1、超期维修 1、维修待确认 1；点每一项能跳到对应页 |
| BOSS-02 | 金额遮挡 📷 | 工作台点眼睛图标，进库存、销售详情、报表；再关闭 | 金额全部遮挡，切换页面后保持；关闭后恢复。只遮屏幕 |
| BOSS-03 | 库存总览（基线） 📷 | 库存页 | 在库 53 台，零售总额 ¥428,550.98，在库成本 ¥377,135.06；状态标签带数量；全部 74 台，滚动能加载完 |
| BOSS-04 | 库存查找 | 分别用 `Mate`、完整串码 `359999000000034`、编号 `t03` 搜索；型号筛选、库龄 30、价格区间；点「重置全部」 | 结果正确；库龄 30 含 t06、t07、t30；最低价大于最高价提示「最低价不能高于最高价」；库龄填 `abc` 提示「库龄须为 0～36500 天整数」 |
| BOSS-05 | 设备详情 📷 | 打开 t03、t27、t51 | 成本、三价、供应商、内部备注、完整串码、参数都可见；内部凭证能切换查看；流水显示前后状态、操作人、时间；t51 没有改价按钮，分享开关置灰 |
| BOSS-06 | 改价 | t50 → 修改价格：不改直接保存；改零售为 7099 取消弹窗；再改并留空原因；最后填原因 | 依次「价格未修改」、未保存、「请填写操作原因」、保存成功；操作日志记录 |
| BOSS-07 | 单台分享开关 | t50 三个开关逐一关开 | 立即生效；切顾客确认 t50 随之消失和出现，再切回 |
| BOSS-08 | 批量代理转发 📷 | 库存 → 代理转发，勾选 t18、t22 → 开启；再勾选同样两台 → 关闭转发 | 提示成功；切代理确认出现再消失。不可售设备不能勾选 |
| BOSS-09 | 报表 📷 | 报表页切今日、本周、本月；趋势指标；维度切型号、员工、门店 | 数据随切换刷新；分母为 0 时动销率显示 `--`；有毛利、毛利率；图表文字清晰 |
| BOSS-10 | 库龄预警 | 报表 →「当前库龄预警」 | 超过 30 天 4 台（u3、t06、t07、t30）；点击进设备详情 |
| BOSS-11 | 代理收益对账 | 报表里的代理收益对账，点张代理 | 进入收益页，顶部「仅看代理 张代理 的收益记录」；「查看全部代理」可切回 |
| BOSS-12 | 导出 📷 | 点「填写原因并导出销售退款明细」，先取消；再填原因确认 | 取消无影响；生成后出现「保存并分享CSV文件」；日志有记录 |
| BOSS-13 | 新增分类 | 型号模板 → 新增分类：空名称保存；填「游戏掌机」，选复制手机模板保存；再改分类名 | 空名称提示「请填写分类名称」；成功后出现新分类，有自己的模板 |
| BOSS-14 | 新增型号 | 新增型号：缺字段保存；填齐品牌、系列、型号、容量、颜色保存；填 TAC 不填来源 | 缺字段提示「请填写品牌、系列和型号」；TAC 缺来源被拦截；新型号出现在入库选择器和顾客分类里 |
| BOSS-15 | 编辑模板 📷 | 手机模板 → 新增自定义字段「屏幕维修史」，选类型、可见范围，保存字段，发布新版本 | 提示「新版本已发布」；版本历史多一条；旧设备保留原快照；入库表单出现新字段 |
| BOSS-16 | 模板字段操作 | 上移、下移、删除字段；未发布就退出 | 操作生效；删除有确认；未发布时切模板提示「请先发布修改，或退出后重新进入」 |
| BOSS-17 | 新增员工 📷 | 员工页 → 新增：空姓名、错手机号；填齐选销售；填原因 | 依次「请填写姓名」「请填写 11 位手机号」；成功后列表出现 |
| BOSS-18 | 员工管理 | 编辑 BOSS-17 新增员工的角色；停用、恢复；解绑小李微信；尝试停用自己 | 每步要求原因；不能停用自己；已停用员工「已离职员工」可筛出 |
| BOSS-19 | 角色权限 📷 | 员工页进角色设置，切每个角色，勾选后还原；老板角色 | 老板显示「老板角色固定拥有全部权限与字段」；未保存切换提示「请先保存或还原当前修改」。实际收回权限在 FLOW-28 |
| BOSS-20 | 操作日志 📷 | 操作日志，按动作、操作人、日期筛选，展开详情，清除筛选 | 能看到前面改价、新增员工的记录，含原因；日志不可编辑 |
| BOSS-21 | 代理审核 📷 | 代理审核 → 待审核：林晓留空上限点通过；周凯填上限 `abc`；周凯点拒绝 | 林晓用默认上限 ¥300；`abc` 提示「上限须为不小于 0 的金额，最多两位小数」；审核需填说明；各筛选页状态正确 |
| BOSS-22 | 代理设置 | 把默认上限改 400；调整陈晨上限；恢复郑浩后再停用 | 都要求原因并记录日志；旧值保留到保存后才变 |
| BOSS-23 | 代理订单与收益 | 进代理订单、代理收益页 | 能看到分享价、加价、收益，可勾选待转账记录。实际转账在 10-财务 |
| BOSS-24 | 我的 📷 | 员工端「我的」：入口列表、金额遮挡开关、切换到顾客端、退出登录 | 入口齐全且可跳转；退出后回到顾客身份 |
