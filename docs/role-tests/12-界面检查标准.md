# 12 界面检查标准

两种时机都要看：

- **走用例时**：标了 📷 的步骤，当前主题下截图判断。
- **全站巡检**：所有业务走完、数据最丰富时，下表 59 页每页在浅色、深色、零售绿三套主题下各截一张。页面超过一屏时滚动补拍，底部按钮区必须拍到。

不要只看第一屏，也不要只看列表：弹层、展开的筛选、错误提示、空状态、禁用按钮都算界面。

## 判断项

### A 文字看不看得清

| 项 | 不合格的表现 | 级别 |
|---|---|---|
| A1 正文对比度 | 文字与背景颜色接近，需要凑近才看清 | P1 |
| A2 按钮文字 | 深色底配深色字、浅色底配白字，典型如深色主题下白色实心按钮上的白字 | P1 |
| A3 次要文字 | 灰字落在灰底上无法辨认，如筛选标题、备注、时间 | P2 |
| A4 金额 | 价格、合计看不清，或与背景颜色相近 | P1 |
| A5 占位提示 | 输入框 placeholder 与背景融为一体 | P2 |
| A6 输入内容 | 输入后的文字看不见 | P1 |
| A7 字号 | 主要信息小到需要放大才能读 | P2 |

参考标准：正文和按钮文字对比度不低于 4.5:1，大号文字不低于 3:1。拿不准时取色计算，并在报告里写出前景色、背景色和比值。

### B 颜色有没有用错

| 项 | 不合格的表现 | 级别 |
|---|---|---|
| B1 主题残留 | 深色主题下出现大块白底或浅灰卡片；浅色主题下出现黑块 | P1 |
| B2 状态含义 | 状态标签颜色与含义相反，如“异常”显示绿色、“已通过”显示红色 | P1 |
| B3 标签可辨 | 不同状态标签颜色相同导致难以区分，或文字与标签底色接近 | P2 |
| B4 选中态 | 看不出哪个标签、筛选、分段被选中 | P1 |
| B5 禁用态 | 禁用和可点击的按钮看起来一样 | P2 |
| B6 图标 | 深色主题下图标黑色隐入背景；图标与文字颜色明显不协调 | P1 |
| B7 零售绿 | 主块、底栏文字对比不足；绿色用在不该强调的地方 | P2 |
| B8 系统组件 | 开关、选择器、弹窗在深色主题下刺眼或看不清 | P2 |
| B9 负数和警告 | 负数、逾期、超期、差异没有醒目区分 | P2 |

### C 布局

| 项 | 不合格的表现 | 级别 |
|---|---|---|
| C1 遮挡 | 底部导航或底部按钮挡住内容；最后一项滚不出来 | P1 |
| C2 溢出 | 文字、金额超出卡片，出现横向滚动 | P1 |
| C3 截断 | 关键信息被截断且无法查看全文 | P2 |
| C4 对齐 | 同类元素明显错位，表格列不齐 | P3 |
| C5 拥挤 | 按钮挤在一起容易误触 | P2 |
| C6 空状态 | 空页面只有一片空白，没有说明 | P2 |
| C7 加载 | 长时间白屏，或加载状态闪烁、残留 | P2 |
| C8 图片 | 破图、变形、占位缺失 | P2 |

重点用这些设备检查：t25（¥99,999.99 大金额）、t27（超长名称和描述）、t28（无图）、t29（无描述）。

### D 一致性

| 项 | 不合格的表现 | 级别 |
|---|---|---|
| D1 新页面漏主题 | 某页切深色后没变化，或局部组件没跟着变 | P1 |
| D2 同类样式 | 同样的按钮、卡片、标签在不同页面样式不同 | P3 |
| D3 技术词 | 界面显示英文字段名、接口错误原文、`undefined`、`null`、`NaN` | P1 |
| D4 待办标记 | 页面露出开发用的 todo 块（标签页、收银页已知有，记录但不算新缺陷） | P3 |

## 三套主题重点

| 主题 | 最容易出问题的地方 |
|---|---|
| 浅色 | 灰字落在灰底上；白卡片与背景分不开 |
| 深色 | 白底残留；`background: var(--c-ink)` 的块变成大白块；图标不反色；系统弹窗、开关、选择器；品牌色按钮上的文字；海报页；图表线条和坐标文字 |
| 零售绿 | 主块上的文字、底部导航文字；绿色块与状态标签的绿色混淆；卡片内凹槽的对比 |
