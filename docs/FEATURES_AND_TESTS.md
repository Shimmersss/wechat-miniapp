## 三、手动测试需要覆盖的操作

### 测试前准备

- 微信开发者工具导入仓库根目录。默认 `useMock: true`，数据在内存里，**重新编译会清空本轮新增的数据**。
- 切换身份：“我的 → 开发调试 / 切换模拟身份”，或员工登录页选角色。
- 每一项都检查：控制台没有报错、没有 `[mock] 未实现` 警告、没有 WXML 警告。
- 记录问题格式：入口 → 当前身份 → 操作步骤 → 实际结果 → 期望结果（附截图）。
