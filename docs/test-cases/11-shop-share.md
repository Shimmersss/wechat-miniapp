# 11 顾客端与分渠道分享

涉及接口：`GET /shop/home`、`GET /shop/units`、`GET /shop/units/:id`、`POST /share/links`、`GET /shop/shares/:id`、`PATCH /share/links/:id/revoke`、`GET /share/links/:id/copywriting`、`GET /share/links/:id/poster`
涉及页面：`pages/shop|category|mine`、`shop/search|product|poster|collection`、`staff/share`

渠道由服务端决定：无分享看身份（同行→批发价，其他→零售价），有 `X-Channel: <shareId>` 按分享快照。
