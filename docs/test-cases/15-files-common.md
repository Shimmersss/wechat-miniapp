# 15 文件与接口通用规则

涉及接口：`POST /files`、`GET /files/:id`、`GET /files/:id/content`，及所有接口的通用行为。

## 15.1 上传

| 编号 | 级 | 层 | 身份 | 步骤 | 预期 |
|---|---|---|---|---|---|
| FIL-001 | P0 | API | 采购 | 上传 JPEG、PNG、WebP，scope=public | 成功；按文件魔数识别；审计「上传文件」 |
| FIL-002 | P1 | API | 采购 | 上传 MP4，scope=public | 成功 |
| FIL-003 | P0 | API | 采购 | MP4 且 scope=internal | 400「收货凭证请上传图片」 |
| FIL-004 | P0 | API | 采购 | 把 exe、html 改名为 .jpg | 400「仅支持 JPEG、PNG、WebP 或 MP4」 |
| FIL-005 | P1 | API | 采购 | 截断的图片 | 400「文件内容不完整」 |
| FIL-006 | P1 | API | 采购 | 超过 32MB | 413「文件超过允许大小」，临时文件被清理 |
| FIL-007 | P1 | API | 采购 | 一次传两个文件 | 400「只允许上传一个文件」，或多分片限制 |
| FIL-008 | P1 | API | 采购 | 不传 scope、scope=xxx、不带文件 | 400「请上传文件并指定 public/internal 范围」 |
| FIL-009 | P0 | API | 销售 | scope=public | 403（销售只能传内部凭证） |
| FIL-010 | P0 | API | 工程师 | scope=internal | 成功 |
| FIL-011 | P0 | API | 顾客 | 上传 | 403 |
| FIL-012 | P2 | API | 同一人 | 1 分钟第 31 次 | 429 |
| FIL-013 | P0 | 数据 | 任意 | 失败上传后查 staging 目录 | 无残留 |
| FIL-014 | P1 | 数据 | 任意 | 文件目录权限 | 0700，文件 0600 |

| 编号 | 级 | 层 | 身份 | 步骤 | 预期 |
|---|---|---|---|---|---|
| FIL-020 | P0 | API | 匿名 | 读公开文件内容 | 200；Cache-Control public；nosniff |
| FIL-021 | P0 | API | 匿名 | 读内部文件，无签名 | 401「凭证链接无效或已过期」 |
| FIL-022 | P0 | API | 匿名 | 内部文件带有效签名 | 200；Cache-Control `private, no-store` |
| FIL-023 | P0 | API | 匿名 | 篡改 signature、sid、expires | 401 |
| FIL-024 | P0 | API | 匿名 | 超过 5 分钟 | 401 |
| FIL-025 | P0 | API | 员工 | 退出登录后用旧签名 | 401（会话撤销，签名立即失效） |
| FIL-026 | P0 | API | 顾客 | `GET /files/:id` 读内部文件 | 403 |
| FIL-027 | P1 | API | 任意 | 文件不存在 | 404「文件不存在」 |
| FIL-028 | P0 | API | 库管 | 读收款凭证 | 403 |
| FIL-029 | P0 | API | 无 loan:manage 员工 | 读借还凭证 | 403 |
| FIL-030 | P0 | API | 工程师/店长 | 读维修费用凭证 | 无权限；费用同时关联销售时不能绕过 |
| FIL-031 | P0 | 数据 | 全局 | 一个文件关联多业务 | 须同时满足每个业务的授权 |
| FIL-032 | P0 | 并发 | 两人 | 同一内部图片同时被两种业务认领 | 只有一方成功 |
| FIL-033 | P0 | 数据 | 顾客 | 所有 `/shop/*` 响应 | 不含 internal 文件 URL |

## 15.3 通用接口规则

| 编号 | 级 | 层 | 身份 | 步骤 | 预期 |
|---|---|---|---|---|---|
| COM-001 | P0 | API | 任意 | 抽查成功响应 | `{code:0,data,message:"ok"}` |
| COM-002 | P0 | API | 任意 | 抽查失败响应 | `{code:<状态>,data:null,message}`，HTTP 状态与 code 相同 |
| COM-003 | P1 | API | 任意 | 不存在的路径 | 404「接口不存在」 |
| COM-004 | P0 | API | 任意 | 触发 500 | 「服务暂不可用，请稍后重试」；不泄露 SQL、路径、堆栈 |
| COM-005 | P1 | API | 任意 | 触发死锁、锁等待超时 | 409「数据正在被其他操作更新，请重试」 |
| COM-006 | P1 | API | 任意 | 唯一键冲突 | 409「记录重复或映射冲突，请核对后重试」 |
| COM-007 | P1 | API | 任意 | body 超 1MB | 413 信封 |
| COM-008 | P1 | API | 任意 | 全局每分钟 181 次 | 429「请求过于频繁，请稍后重试」 |
| COM-009 | P1 | API | 任意 | 响应头 | X-Content-Type-Options=nosniff；Cache-Control=no-store |
| COM-010 | P0 | API | 任意 | 全部列表接口 | `{list,total,page,pageSize}` |
| COM-011 | P1 | API | 任意 | 金额 | 单位为元，`0.1+0.2` 不出现浮点误差；内部按分计算 |
| COM-012 | P1 | API | 任意 | 文本字段前后空格、纯空格 | 去空格；纯空格按未填 |
| COM-013 | P0 | API | 攻击者 | keyword 含 `' OR 1=1 --`、`%`、`_` | 参数化查询，无注入 |
| COM-014 | P0 | API | 攻击者 | 文本含 `<script>` | 原样存储，页面不执行 |
| COM-015 | P0 | 数据 | 全库 | 用 readonly 账号读敏感字段、用 runtime 账号改结构 | 按账号隔离拒绝 |
| COM-016 | P0 | 代码 | 全仓 | 扫描 `miniprogram/` | 无密钥；不引用根目录 `.env` |
| COM-017 | P0 | 代码 | 全仓 | 提交前 `./scripts/appid.sh` | 显示 repo AppID |
| COM-018 | P1 | API | 重启 | 服务重启后 | 会话、数据、文件保留；未完成事务无半成品 |
| COM-019 | P1 | API | 采购 | 采购金额合计超过 999999999999.99（1000 台×超大单价，多行累加） | 400「金额合计超出允许范围」 |
| COM-020 | P2 | 单元 | 开发 | 直接调 `cents()`：999999999999.99、1000000000000 | 前者通过；后者格式校验拒绝；「金额超出允许范围」分支由正则先拦截，确认是否死代码 |
| COM-021 | P2 | 单元 | 开发 | 构造“持有员工权限点但无 staffNo”的用户调用各防御分支 | 403「仅员工可操作」「仅员工可跟进顾客资料」「仅员工可管理借还」「仅员工可查看维修单」「仅员工可查看维修选项」「仅员工可查看」；正常角色走不到这些分支 |
| COM-022 | P2 | 单元 | 开发 | `resolve(..., {ownerOnly:true})` 非所有者；分享无明细的脏数据 | 403「无权管理该分享」；404「分享暂无商品」 |
