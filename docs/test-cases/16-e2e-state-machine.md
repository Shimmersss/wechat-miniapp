# 16 端到端流程与状态机

每条流程跨多个模块，建议在 mock 和真实后端各跑一遍。每一步都核对：设备状态、库存流水、审计日志、统计数字。

## 16.2 主流程

| 编号 | 级 | 身份 | 流程 | 关键检查点 |
|---|---|---|---|---|
| E2E-001 | P0 | 采购→库管→店长→销售→财务 | **采购到销售闭环**：建供应商→采购 2 台→录运单→签收→验收通过→改价→开分享→顾客看到→收银→查报表 | 在途不可售；签收前不能验收；成本来自采购单；成交快照；工作台数字逐步变化 |
| E2E-002 | P0 | 采购→库管→老板 | **验收异常闭环**：3 台到货→1 台型号不符→记异常→争议→复验通过；另 1 台退回 | 采购单 exception→completed；串码不可重复；库存 2 台；异常退回台不入库 |
| E2E-003 | P0 | 销售→财务→库管→销售 | **退货再售**：售出→差价退款→整机退货→复检不通过→复检通过→重新开分享→再售 | 流水首尾相接；分享不自动打开；两张单毛利都正确；旧单不可再退 |
| E2E-004 | P0 | 工程师→店长→财务 | **店外维修**：开单→检测→报价→确认→领料→改报价作废确认→重新确认→维修→收款→取机 | 串码占用与释放；毛利=收入−配件−费用；质保天数 |
| E2E-005 | P0 | 工程师→店长→库管 | **本店机送修**：在库→送修→领料→完工→复检→可售 | 维修中不可售、不可分享；成本按策略累加一次；复检后分享全关 |
| E2E-006 | P0 | 店长 | **维修取消退款**：收款→领料→退料→退款→取消 | 未退清不能取消；配件数量和价值守恒 |
| E2E-007 | P0 | 库管 | **出借闭环**：多选出借→部分归还→复检→完结→全部归还→完结 | 不计销售；单据状态 active→returned_recheck→closed；工作台待办 |
| E2E-008 | P0 | 库管 | **借入闭环**：借入→不可售→归还→再次借入同机→归还 | 无成本、无收入；货权冲销；复用原 unit |
| E2E-009 | P0 | 顾客→老板→代理→顾客→销售→财务 | **代理全流程**：申请→审核→开放转发→加价→分享→下单锁库→收银→记收益→标记转账 | 分享价=底价+加价；顾客看不到底价；收益=加价快照 |
| E2E-010 | P0 | 财务 | **代理退货**：E2E-009 后整机退货，再有新订单→转账 | 冲回负记录；待转账抵扣；统计对账一致 |
| E2E-011 | P0 | 顾客→系统 | **锁库到期**：下单→不处理→到期释放→他人重新获取分享下单 | 设备回 in_stock；首单 released；不算成交 |
| E2E-012 | P0 | 同行→销售 | **同行意向**：打开同行分享→看批发价→发起意向→员工跟进→按批发价成交 | 同行不能直接下单；归因保留 |
| E2E-013 | P0 | 顾客→销售 | **预约到店**：预约→确认→到店→开单→预约完成 | 预约期间不锁库；其他人可买走；买走后意向开单 409 |
| E2E-014 | P0 | 库管 | **盘点闭环**：开单→多人扫码→期间售出 1 台→结束→处理差异 | 库存状态不被盘点修改；差异只追加 |
| E2E-015 | P0 | 老板→店长 | **权限变更**：收回字段→页面、接口、日志、导出全部同步 | 不需重新登录 |
| E2E-016 | P0 | 老板 | **员工离职**：停用→令牌失效→其分享链接失效→其维修单改派 | 分享 410；历史记录保留 |
| E2E-017 | P1 | 老板 | **模板升级**：发布新版本→旧机详情不变→新入库用新版本→复检沿用旧快照 | 快照隔离 |
| E2E-018 | P1 | 全部 | **一台设备全生命周期**：验收→销售→退货→复检→送修→复检→出借→归还→复检→代理下单→释放→成交 | 流水连续；分享开关每次归零 |
| E2E-019 | P0 | 全部 | **跨日经营对账**：一天内混合 销售、退款、维修、出借 | 工作台、报表、CSV 三处金额一致 |
| E2E-020 | P0 | 运维 | **备份恢复**：mysqldump + `.local/files` 备份→恢复到新实例→跑 E2E-001 查询 | 数据与文件完整（尚未演练） |
