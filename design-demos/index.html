夏目数码 · UI 方案索引

这是纯设计稿，不参与小程序构建，也不被 miniprogram/ 引用。 七个方案都是独立的静态 HTML（手写 CSS，无框架），假数据，直接双击打开即可看。 它们共用同一套 66 个手绘 SVG 图标（icons-v2.js）和两张 AI 生成的产品图（assets/）。 主推 01 / 02 / 03 / 07，其余三个留作备选和风格参考。

白底 + 分组标题 + 白底圆角方卡托图标，顶部深绿品牌区。结构最接近原始参考图，落地成本最低。
白底 · 方卡 · 高密度打开 ↗
D · 暖阳果冻02-candy
橙→粉→紫暖阳渐变底，圆角 26px，图标衬白底装在果冻质感方块里。热、亲切、有活力。
渐变 · 果冻 · 暖打开 ↗
F · 柔光珐琅03-enamel
莫兰迪柔光底（淡紫→雾蓝→浅粉），半透明玻璃卡片，图标像珐琅胸针。凉、静、克制。
玻璃 · 莫兰迪 · 凉打开 ↗
G · 雾白层叠07-frost
全白色系。不靠颜色靠虚化分层：淡彩光晕 → 白卡 → 毛玻璃主卡 / 悬浮玻璃底栏，卡内做成灰色凹槽。最干净，但依赖 backdrop-filter。
白 · 毛玻璃 · 克制打开 ↗

目录里都有什么

路径内容
index.html就是这个页面，七个方案的索引
README.md交接文档：设计思路、每个方案的取舍、如何翻成小程序
compare.html / compare.pngA / D / F 三版「我的」页并排对比
icons-v2.js66 个手绘 SVG 图标库，通过 <script> 注入为 symbol，各方案用 <use href="#i-xxx"> 引用
assets/两张 AI 生成的产品图（蓝/白），各方案用 CSS hue-rotate 派生其他配色
shoot.sh无头 Chrome 截图脚本：./shoot.sh 01-retail-tool 重新生成 preview.png
01–07每个方案一个目录，内含 index.html（可直接打开）和 preview.png
怎么用这些稿子。 这些 HTML 是给设计讨论和实际开发参考用的视觉基准，不是可以直接上线的代码。 真要落地时，从 01-retail-tool 或 02-candy 里把 CSS 变量（颜色、圆角、阴影）和 icons-v2.js 的 path 数据搬到 miniprogram/styles/theme.wxss 和 miniprogram/assets/icons/ 即可。具体拆法见 README.md 的「如何翻成小程序」一节。
